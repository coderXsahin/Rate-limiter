# Rate Limiter

A Python backend project implementing rate limiting to control how frequently clients can access API endpoints.

## Features

- Sliding Window rate-limiting algorithm
- Token Bucket rate-limiting algorithm
- Isolated state for each client and endpoint
- Thread-safe request decisions
- HTTP API and rate-limit statistics
- Automated tests

## Tech Stack

- Python
- FastAPI
- Pytest
- Git and GitHub

Currently in development.
